# Contributing Guide

## Branching & Pull Requests
- Create feature branches from `main` using `feature/<card-number>-<slug>` (for example `feature/18-draft-ddl`).
- Follow Conventional Commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).
- Ensure `make test` and `make lint` pass with **70%+ backend test coverage** before opening a PR.
